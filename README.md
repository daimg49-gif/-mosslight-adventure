# 小屋大冒險 · 苔光小院

## 製作進度

- 第一版（已實作）：保留庭院展示；由按鈕或點擊前門進屋；完整立體客廳；正常／約 1:8 迷你視角；手機方向鍵與桌面 WASD；拖曳環視；五個探索角落；三種微小物件及玻璃瓶的觀察文字；回庭院。
- 第二版（已實作）：滑蓋木盒、尺橋與書堆、玩具車與紙盒通道；三個獨特零件；真實坡道與動態碰撞；恢復裝置完成流程；同瀏覽器 localStorage 進度保存及重新開始。
- 第三版（已實作）：可往返的玻璃溫室；植物、露珠、花朵、銅壺與種子盤；花朵輕擺與水面漣漪；可開關的程序化環境音；客廳與溫室共九種發現的持久探索圖鑑。

美術優先：真實幾何屋瓦、石牆與庭院；室內木地板接縫、牆板、編織地毯與立體纖維、軟墊沙發、書架、茶具、玻璃瓶、壁爐、油畫與窗簾。材質由 Canvas 程式繪製，並使用暖色窗光、陰影與浮塵。這是原創程序化美術展示，非商業遊戲素材。

## 操作

庭院：拖曳旋轉，雙指／滾輪縮放。按「推門進屋」或點擊前門。

客廳：拖曳環視、WASD／箭頭鍵／畫面方向按鈕移動。「縮小」切換尺度，「探索角落」切換觀察位置。「觀察」或 E 檢查準星前的物件。正常大小不能穿過家具，縮小後可進入茶几及沙發下方；恢復大小遇到家具時回到入口。

## 第三版操作

「找側門」將玩家帶至客廳東側門前；按「推門進溫室」。溫室也可走動及縮小。靠近五種微觀景觀，按「觀察」或情境按鈕記錄。入口木門可返回客廳，且不會重設謎題進度。

「圖鑑」列出九種發現；未發現的項目不會揭露內容。客廳四種物件需要準星對準並觀察，溫室五種需要靠近並觀察。圖鑑保存在同瀏覽器；重新開始只重設謎題，不會清除圖鑑。

環境音使用 Web Audio 程序化生成風聲、鳥鳴般的短音與壁爐般的輕聲，不載入外部音樂或音訊。必須點選「音效」才能啟用。失去焦點及隱藏頁面時靜音。

第三版已驗證：新房間建立與有限座標、兩種尺度、花床碰撞、側門往返、舊謎題進度保留、五種溫室紀錄及重複記錄、圖鑑開關、再入室、音效選擇啟用／靜音／不支援回退。實際 GPU、美術呈現、iPhone 流暢度及音效聽感仍未驗證。

第二版驗證：錯誤尺度操作、未達條件不取件、封閉路徑碰撞、步行通過尺橋坡道與紙盒入口、三件收集及完成恢復、重複操作、重新開始、存檔恢復及損毀存檔回復。未進行實際瀏覽器 GPU 或 iPhone 驗證。
