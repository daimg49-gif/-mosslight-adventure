- 第二版（已實作）：滑蓋木盒、尺橋與書堆、玩具車與紙盒通道；三個獨特零件；真實坡道與動態碰撞；恢復裝置完成流程；同瀏覽器 localStorage 進度保存及重新開始。

美術優先：真實幾何屋瓦、石牆與庭院；室內木地板接縫、牆板、編織地毯與立體纖維、軟墊沙發、書架、茶具、玻璃瓶、壁爐、油畫與窗簾。材質由 Canvas 程式繪製，並使用暖色窗光、陰影與浮塵。這是原創程序化美術展示，非商業遊戲素材。

## 操作

庭院：拖曳旋轉，雙指／滾輪縮放。按「推門進屋」或點擊前門。

客廳：拖曳環視、WASD／箭頭鍵／畫面方向按鈕移動。「縮小」切換尺度，「探索角落」切換觀察位置。「觀察」或 E 檢查準星前的物件。正常大小不能穿過家具，縮小後可進入茶几及沙發下方；恢復大小遇到家具時回到入口。
